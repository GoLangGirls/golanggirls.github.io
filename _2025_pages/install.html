Installation Guide

    • Windows Installation

      • Download the zip file and extract it into the directory of your choice. By default, Go will be installed in C:\Program Files\Go.
      • Set the GOPATH environment variable according to your workspace: 
        NOTE: GOPATH must not be the same path as your Go installation.
        > Open Settings and click on System.
        > Scroll down and click on About.
        > Click on Advanced system settings.
        > Click the Environment Variables button.
        > Under User variables, click New.
        > Enter GOPATH as the Variable name.
        > Enter C:\Program Files\Go as the Variable value.
        > Click OK.
      • For more information follow this link

    • Linux Installation

      • Execute the following commands to install Go: 
        wget https://golang.org/dl/go1.24.1.linux-amd64.tar.gz

sudo tar -xzf go1.24.1.linux-amd64.tar.gz -C /usr/local/
      • Set up Go paths: 
        sudo nano ~/.bashrc
        At the end of the file, add these lines: 
        export PATH=$PATH:/usr/local/go/bin
export PATH=$PATH:/home/<user_name>/go/bin
        Save and close the file, then run: 
        source ~/.bashrc
      • To check the installed Go version: 
        go version
      • For more information follow this link

  1. Mac Installation

    • Install Go using Homebrew: 
      brew install golang
    • Verify the installation: 
      go version
